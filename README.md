# Text Frequency Analyzer

A Python program designed to process text files and calculate character and word frequencies.

## Features
* **File Reading:** Reads the contents of the target text file[span_0](start_span)[span_0](end_span).
* **Frequency Calculation:** Calculates the frequency of letters and words[span_1](start_span)[span_1](end_span).
* **Screen Output:** Displays the top ten most frequent characters and words in the console[span_2](start_span)[span_2](end_span).
* **Detailed Reports:** Generates `characters.txt` and `words.txt` containing detailed analysis data[span_3](start_span)[span_3](end_span).

## Requirements
* Python 3.x environment[span_4](start_span)[span_4](end_span).
* A `.txt` text file encoded in UTF-8[span_5](start_span)[span_5](end_span).

## Usage
1. Run the script with Python 3[span_6](start_span)[span_6](end_span):
```bash
python main.py
```
2. When prompted, enter the filename of the `.txt` file you want to analyze (e.g., `input.txt`)[span_7](start_span)[span_7](end_span).

## Output Files
The script generates the following files containing detailed data[span_8](start_span)[span_8](end_span):
* `characters.txt`: Detailed frequency counts for individual letters[span_9](start_span)[span_9](end_span).
* `words.txt`: Detailed frequency counts for words[span_10](start_span)[span_10](end_span).

## Notes
* The program analyzes only English letters (a–z)[span_11](start_span)[span_11](end_span).
